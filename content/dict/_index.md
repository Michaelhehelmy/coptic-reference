# Dictionary

11,369 entries merged from the Comprehensive Coptic Lexicon, a Kaikki.org extract
of Wiktionary, and the sources listed under [Licences](/licences/).

The data is built, licence-checked and fingerprinted; the entry lookup is
fetched by your browser rather than baked into a page, so there is no server
between you and it. With JavaScript off there is nothing to show here — see the
note below.
