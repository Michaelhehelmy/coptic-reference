# Dialects

Bohairic is presented first throughout this site because it is the language the
living Church uses. That is a **presentation** decision. It is not a claim that
the sources record Bohairic as often as they record Sahidic, and this page exists
so the difference is visible rather than asserted.

Counts are computed from the shipped data by
`tools/emit/dialects.py` and checked against the shards by
`tools/validate/dialects_check.py` — the file this page will render from is
`data/dist/dialects.json`.

**1,631 of 11,369 entries (14%) have no dialect recorded by any source.** They are
shown, with a visible note, and never filtered out. An entry the sources are
silent about is not the same as an entry that does not exist.

Five codes — `L`, `M`, `P`, `V`, `W`, covering about 1,600 entries — are CCL
codes whose expansions this project has not established. They are displayed
verbatim rather than guessed.
